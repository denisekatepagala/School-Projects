Project Phasing

(Completed) Part 1: Basic OCR + English → Tagalog translation 
- Build the core pipeline without the dataset. Test by giving it a simple English word/sentence, e.g. "apple" → "mansanas". First verify OCR separately, then translation.

(Completed) Part 2: Dataset 
- Get OCR dataset, Clean/prepare dataset, Create 300 usable samples, Train/validation split (240/60)

(Completed) Part 3: 100-word processing
- Add your OCR dataset and evaluate the system. Make sure the system can process images containing up to 100 English words. Measure OCR/translation results and processing time.

(Completed) Part 4: UI & FastAPI
- Build the user interface and backend. User should be able to upload/capture an image → process it → display English OCR text → display Tagalog translation.

(Completed) Part 5: Raspberry Pi Integration
- Move/test the complete software stack on the Raspberry Pi 4B. Check whether OCR, translation, FastAPI, and UI work properly on the Pi.

(Completed) Part 6: USB Camera & Final Integration
- Connect the USB webcam, capture an image directly from the camera, send it through the pipeline, display the English and Tagalog results, then perform final testing.
